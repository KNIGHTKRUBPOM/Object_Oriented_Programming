# 💡 OOP Practice Exercises & Design Problems

A collection of standalone object-oriented programming challenges focusing on design patterns, class modeling, encapsulation, and domain simulations.

---

## 📚 Problem Catalog

| Script | Topic / Scenario | Key OOP Concepts |
| :--- | :--- | :--- |
| [`Bank_Encap.py`](Bank_Encap.py) | **Bank Account with Strict Encapsulation** | Private attributes (`__balance`), validation on deposits/withdrawals, balance protection. |
| [`Bank.py`](Bank.py) | **Basic Banking Model** | Initial class definitions, deposit, withdraw, and account balances. |
| [`Hotel.py`](Hotel.py) | **Hotel Reservation System** | Room occupancy management, guest check-in/check-out, billing calculation. |
| [`coffee_shop.py`](coffee_shop.py) | **Coffee Shop POS System** | Menu modeling, order aggregation, item customization, receipt generation. |
| [`Online_Shop.py`](Online_Shop.py) | **Mini E-Commerce Store** | Basic shopping cart, product catalog, and price total calculation. |
| [`Product_Catalog_Search.py`](Product_Catalog_Search.py) | **Case-Insensitive Product Search** | Encapsulated inventory list, string matching, availability flags. |
| [`Car.py`](Car.py) | **Vehicle Simulation** | Speed adjustments, fuel monitoring, engine status tracking. |
| [`Circle.py`](Circle.py) | **Geometry Modeling** | Radius encapsulation, area/circumference calculations, geometric operations. |
| [`Song_Class.py`](Song_Class.py) | **Media Player Entity** | Class attributes, string formatting, method modeling. |
| [`List_Comprehension_Demo.py`](List_Comprehension_Demo.py) | **Python Filtering Idioms** | Functional list comprehensions applied to OOP collections. |
