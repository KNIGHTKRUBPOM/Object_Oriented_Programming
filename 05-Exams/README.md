## 📅 Featured Problem: Multi-Party Appointment Scheduler System

### Problem Description
Design and implement an automated appointment and calendar management system supporting:
1. **Recurring & One-Time Events**:
   - Single date appointments (`date`).
   - Weekly recurring schedules (`day_of_week`).
   - General team activities.
2. **Attendee Management**:
   - Registering participants to meetings.
   - Searching appointments by attendee identity.
3. **Notification Service**:
   - Dispatching SMS notifications dynamically to attendees with valid contact information.
4. **Dynamic Modification**:
   - Updating event titles, venues, and timings.
   - Removing cancelled events cleanly.
